The Office.js API.

formula.js
await Excel.run(async (context) => {
  const sheet = context.workbook.worksheets.getItem("Sheet1");
  sheet.getRange("A1").values = [[10]];
  sheet.getRange("A2").formulas = [["=A1*2"]];

  const result = sheet.getRange("A2");
  result.load("values");
  await context.sync();
  console.log(result.values[0][0]);
});
$ mog -f formula.js -o result.xlsx
20
Saved to result.xlsx

Script with Excel.run, queue edits, and sync to read the results. JavaScript runs inside Mog's embedded QuickJS runtime.

Get started

Install the CLI

Mog 1.0 is being prepared for release. The standalone binary and npm options below apply once that release is published. Build from source in the meantime, with stable Rust and a C compiler:

git clone https://github.com/fundamental-research-labs/mog.git
cd mog
cargo install --path compute/officejs --locked
mog --version

Standalone binary. Once 1.0 is published, download the archive for your platform from GitHub Releases. Verify it against SHA256SUMS, extract it, and put mog (or mog.exe) on your PATH. No Node.js or Excel installation is needed. Linux (x64 and ARM64), macOS (Apple Silicon and Intel), and Windows (x64) archives are listed in the installation guide.

npm. Once 1.0 is published, with Node.js 22 or later:

# Once 1.0 is published
npm install -g @mog-sdk/cli@1
mog --version

Or run without a global install:

# Once 1.0 is published
npx @mog-sdk/cli@1 -f formula.js -o result.xlsx

npm selects an optional package containing the binary for your OS and CPU. The launcher passes arguments through to that binary. Scripts still run in the binary's embedded QuickJS runtime, not in Node.js.

Open source.

Mog implements the Office.js API. Scripts, agents, and pipelines can open, edit, recalculate, and save .xlsx workbooks from the terminal. One command edits a file, or a session keeps it in memory across commands.

Mog is open source under Apache-2.0. Read the code on GitHub ↗.
